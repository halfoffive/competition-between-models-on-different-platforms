# 我的世界 (VoxelCraft) 仿制游戏 Spec

## Why

在 Web 端复刻 Minecraft 核心玩法，让用户无需安装客户端即可在浏览器中体验方块世界的建造、探索、生存与创造乐趣。基于 Vite + Vue + Three.js 构建单页应用，使用现代前端工程栈实现可扩展、体素化的沙盒游戏。

## What Changes

- **新增** 基于 Three.js 的体素世界渲染引擎（区块加载、网格合并、材质系统）
- **新增** 程序化世界生成（多生物群系、洞穴、矿物、地形）
- **新增** 第一人称玩家控制器（WASD + 鼠标视角 + 跳跃 + 疾跑 + 潜行 + 飞行）
- **新增** 完整的方块系统（破坏、放置、碰撞、AABB）
- **新增** 物品栏 + 合成系统（3×3 工作台、熔炉冶炼、配方表）
- **新增** 生存机制（生命值、饥饿度、昼夜循环）
- **新增** 生物系统（被动生物：猪、牛、羊、鸡；敌对生物：僵尸、骷髅、爬行者、蜘蛛；AI 行为树）
- **新增** 创造模式（飞行、无限方块、瞬时破坏）
- **新增** HUD 界面（Vue 组件，跨屏渲染，热栏、物品栏、合成界面、生命/饥饿条、调试信息）

## Impact

- **Affected specs**: 无（全新项目）
- **Affected code**: 全部位于 `trae-work-cn/minimax-m3/` 目录下
- **依赖**: Vue 3.x、Vite 5.x、Three.js 0.16x、TypeScript 5.x
- **被禁止访问**: 工作区其他任何目录，仅可读写 `trae-work-cn/minimax-m3/`

## ADDED Requirements

### Requirement: 体素世界引擎

系统 SHALL 提供基于区块（Chunk，16×256×16）的体素世界存储与渲染。

#### Scenario: 区块加载
- **WHEN** 玩家移动到新坐标
- **THEN** 系统异步加载其周围半径 N（默认 4）个区块，并按距离优先级调度
- **THEN** 已加载区块进入渲染队列，生成合并 Mesh 后显示

#### Scenario: 区块卸载
- **WHEN** 玩家远离某区块超过卸载距离（默认 6）
- **THEN** 该区块数据序列化后保留在内存缓存，Mesh 被释放

#### Scenario: 区块生成
- **WHEN** 区块首次被请求
- **THEN** 通过基于种子的多维柏林/值噪声生成地形高度图
- **THEN** 在海平面以下填充石头，沙子覆盖沙滩
- **THEN** 按高度与生物群系放置草方块、泥土、树、矿物

### Requirement: 方块系统

系统 SHALL 支持至少 30 种方块类型，覆盖原版核心方块：

**自然方块**：草方块、泥土、石头、沙子、砾石、基岩、雪块
**木材方块**：橡木原木、橡木木板、橡木树叶
**矿物方块**：煤矿石、铁矿石、金矿石、钻石矿石、红石矿石
**功能方块**：工作台、熔炉、箱子（简化）、火把（简化）
**流体方块**：水、熔岩
**特殊方块**：玻璃、TNT（简化爆炸）、草径

#### Scenario: 破坏方块
- **WHEN** 玩家对非基岩方块按住破坏键 ≥ 破坏时间
- **THEN** 该方块被移除，对应方块作为物品掉落到玩家附近

#### Scenario: 放置方块
- **WHEN** 玩家在持选中的可放置方块时右键点击方块面
- **THEN** 若目标位置无碰撞且在世界中，则放置该方块并扣减物品栏数量

#### Scenario: 物理碰撞
- **WHEN** 玩家或生物尝试进入实心方块占据的体素
- **THEN** 阻挡运动并按面法线推回

### Requirement: 玩家控制器

系统 SHALL 提供第一人称视角与平滑运动。

#### Scenario: 移动
- **WHEN** 玩家按下 W/A/S/D
- **THEN** 玩家朝当前朝向水平移动，并具备加速曲线

#### Scenario: 跳跃
- **WHEN** 玩家在地面按下空格
- **THEN** 给予垂直冲量 8.0 m/s，受重力 -32 m/s² 影响

#### Scenario: 疾跑
- **WHEN** 玩家按住左 Shift + W
- **THEN** 移速提升至 5.6 m/s，饥饿消耗加速

#### Scenario: 潜行
- **WHEN** 玩家按住左 Ctrl
- **THEN** 移速降低到 1.3 m/s，不会从方块边缘坠落

#### Scenario: 视角
- **WHEN** 玩家移动鼠标
- **THEN** 相机偏航/俯仰以灵敏度系数更新，俯仰限制在 ±89°

#### Scenario: 飞行（创造模式）
- **WHEN** 玩家双击空格进入创造模式飞行
- **THEN** 重力失效，垂直方向由空格/Shift 控制

### Requirement: 世界生成

系统 SHALL 使用确定性种子生成可重现的多样化地形。

#### Scenario: 生物群系
- **WHEN** 区块被生成
- **THEN** 根据温度/湿度噪声在以下生物群系中选择：
  - 平原、森林、沙漠、针叶林、雪山、海洋、海滩

#### Scenario: 洞穴
- **WHEN** 区块被生成
- **THEN** 使用 3D 噪声生成天然洞穴，并保证不会出现暴露在地表的开口

#### Scenario: 矿物分布
- **WHEN** 区块被生成
- **THEN** 按高度区间概率分布煤、铁、金、红石、钻石矿石簇

#### Scenario: 植被
- **WHEN** 区块被生成
- **THEN** 在草方块上方按生物群系概率生成树、花、草、高草

### Requirement: 物品栏与合成

系统 SHALL 提供 36 格物品栏、9 格热栏、3×3 合成网格、2×2 玩家合成。

#### Scenario: 配方合成
- **WHEN** 玩家将原料按正确图案放入合成网格
- **THEN** 右侧显示产物，单击拾取至物品栏

#### Scenario: 熔炉
- **WHEN** 玩家打开放置的熔炉 UI
- **THEN** 可放置燃料 + 原料，按时间烧制对应产物

#### Scenario: 原版配方
- **GIVEN** 至少实现以下 25 种原版核心配方：
  - 橡木木板（原木）、木棍（板）、工作台（板×4）、熔炉（圆石×8）
  - 木镐/锹/斧/剑/锄（木板+木棍）
  - 石制工具链（圆石+木棍）
  - 铁制工具链（铁锭+木棍）
  - 钻石制工具链（钻石+木棍）
  - 剑（木棍+板/圆石/铁锭/钻石）
  - 熔炼：铁矿→铁锭、圆石→石头、沙子→玻璃、原木→木炭
  - 食物：小麦、面包

### Requirement: 生存与战斗

系统 SHALL 实现经典的生命、饥饿、伤害与死亡循环。

#### Scenario: 生命值
- **GIVEN** 玩家拥有 20 点生命值（10 颗心）
- **WHEN** 受到伤害源（摔落、敌对生物、岩浆、窒息）
- **THEN** 按伤害量扣减并触发无敌帧与画面红色边缘反馈

#### Scenario: 饥饿值
- **GIVEN** 玩家拥有 20 点饥饿值
- **WHEN** 玩家疾跑、跳跃或经过时间
- **THEN** 饥饿值按速率下降；低于 6 时不能疾跑；为 0 时持续扣血

#### Scenario: 死亡
- **WHEN** 生命值归零
- **THEN** 死亡界面出现，重生至世界出生点

#### Scenario: 昼夜循环
- **GIVEN** 一个完整游戏日 = 20 分钟
- **WHEN** 时间推进
- **THEN** 太阳与月亮按轨道运行；18000-24000 刻为可睡眠的夜间

#### Scenario: 睡觉
- **WHEN** 玩家在夜间右键点击床
- **THEN** 若床未被摧毁则进入睡眠画面并快进至白天

### Requirement: 生物系统

系统 SHALL 实现有限但具有代表性的生物 AI。

#### Scenario: 被动生物生成
- **WHEN** 区块被加载且生物群系适宜
- **THEN** 按概率在草地表面生成猪、牛、羊、鸡

#### Scenario: 敌对生物生成
- **WHEN** 区块被加载且光照 ≤ 7 且难度非和平
- **THEN** 按概率在阴暗区域生成僵尸、骷髅、爬行者、蜘蛛

#### Scenario: 行为 AI
- **GIVEN** 每种生物具备行为状态机：
  - 待机、游走、追逐玩家、攻击、逃跑
- **WHEN** 生物每 20 tick 决策一次
- **THEN** 基于 A* 简化寻路或随机游走更新位置

#### Scenario: 战斗
- **WHEN** 玩家或生物在近战范围内
- **THEN** 按攻击伤害公式对目标造成伤害（无敌帧 0.5s）

### Requirement: 创造模式

系统 SHALL 提供与生存并行的创造模式。

#### Scenario: 切换模式
- **WHEN** 玩家通过 F3+F4 或菜单切换
- **THEN** 当前模式切换至创造，UI 状态与能力变化

#### Scenario: 创造能力
- **GIVEN** 创造模式下：
- **THEN** 玩家可飞行，方块瞬时破坏，物品栏中可一键填充任何物品

### Requirement: HUD 与 UI

系统 SHALL 使用 Vue 3 组件化构建游戏内 HUD 与菜单界面。

#### Scenario: 渲染层
- **GIVEN** Three.js Canvas 作为底层 WebGL 视图
- **THEN** HUD 元素（热栏、生命/饥饿条、调试、提示）以 Vue 组件叠加显示

#### Scenario: 物品栏
- **WHEN** 玩家按 E
- **THEN** 显示 36 格物品栏 + 2×2 玩家合成区 + 物品提示

#### Scenario: 暂停菜单
- **WHEN** 玩家按 ESC
- **THEN** 显示"返回游戏/保存/设置/退出"菜单

#### Scenario: 调试信息
- **WHEN** 玩家按 F3
- **THEN** 显示坐标、FPS、面向方块、显存使用等

### Requirement: 存档系统

系统 SHALL 使用 localStorage 序列化世界种子、玩家状态、已加载区块数据。

#### Scenario: 保存
- **WHEN** 玩家暂停或退出
- **THEN** 当前世界种子、玩家坐标、物品栏、修改过的区块被写入

#### Scenario: 载入
- **WHEN** 玩家选择存档
- **THEN** 从 localStorage 恢复世界状态

## 技术架构

### 技术栈

- **构建工具**: Vite 5.x（最新稳定）
- **前端框架**: Vue 3.4.x（Composition API + `<script setup>`）
- **3D 渲染**: Three.js 0.16x
- **语言**: TypeScript 5.x
- **状态管理**: Pinia
- **工具库**: simplex-noise（噪声）, immer（不可变更新）

### 模块划分

```
src/
├── engine/         # 渲染/物理/区块网格核心（纯 TS，与 Vue 解耦）
│   ├── world/      # World, Chunk, BlockId
│   ├── render/     # MeshBuilder, Materials, Atlas
│   ├── physics/    # AABB, Raycast, Player
│   └── mob/        # MobEntity, AI
├── game/           # Vue 集成层
│   ├── stores/     # Pinia stores: player, world, ui
│   ├── components/ # HUD 组件：Hotbar, Inventory, Debug
│   └── views/      # App.vue, Game.vue
├── worker/         # Web Worker：区块生成
├── main.ts
└── App.vue
```

### 性能目标

- 60 FPS @ 1080p（中端 GPU）
- 单帧 < 16ms
- 区块生成不阻塞主线程（Web Worker）
- Mesh 合并 + 视锥剔除 + 远裁剪
